# Automating Computer Tasks with Cindy
## Use this skill when
- You need to perform repetitive or complex tasks across multiple devices.
- You want to leverage AI models for coding, research, or project management.
- You require remote desktop capabilities to control connected computers.

## What it is
Cindy is an open-source AI agent that allows you to manage and automate tasks across various devices. It supports multi-device access, integrates with popular AI models like Claude Code and Codex, and provides a remote desktop feature for hands-on computer operation.

## Steps
1. **Download Cindy**: Visit the [official website](https://cindy.app/download) and download the appropriate version for your operating system (macOS, Windows, Linux, iOS, Android).
2. **Install Cindy**:
   - For desktop: Follow the installation instructions specific to your OS.
   - For mobile: Use the App Store or Google Play to install Cindy on your device.
3. **Sign In**: Create an account or sign in using existing credentials.
4. **Connect Devices**: Pair your devices by signing in with the same account and enabling necessary permissions.
5. **Configure Models**: Add supported AI models (e.g., Claude Code, Codex) through the Cindy interface.
6. **Set Up Automations**: Define recurring tasks or automations within Cindy to streamline your workflow.

## Checks
- Ensure all devices are online and connected to the same network.
- Verify that necessary permissions for remote access and model sharing are enabled.
- Confirm that AI models are properly configured and accessible through Cindy.

## Pitfalls
- **Security Risks**: Be cautious with remote access features. Only enable them on trusted networks and devices.
- **Billing Issues**: Some AI models may have subscription fees. Ensure you understand the billing structure before using them extensively.
- **Compatibility Problems**: Verify that Cindy supports all your required tools and applications across different devices.
