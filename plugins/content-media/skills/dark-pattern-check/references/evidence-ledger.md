# Evidence ledger

The only source of studies, authors, years and effect sizes this plugin may name. Grades are defined in `evidence-grades.md`. Cite rows by id (L04). Print a number only if it appears in the row.

Check codes: **C** citation (authors, year, title, venue, DOI) confirmed against the Crossref record; **F** the stated finding confirmed against the abstract or full text; **S** the finding confirmed only through a secondary summary. All rows checked 2026-10-03. Rows or items whose finding rests on S are marked "secondary" in the Check column: quote their figures as "reported", never as measured fact.

If an effect is not here, say "not in this plugin's ledger", grade it C at most, name the kind of evidence that would settle it (a preregistered replication, a meta-analysis, a field test with guardrails), and cite nothing.

## Header facts (quote these when asked "how big are nudge effects?")

- Published academic nudge trials averaged +8.7 percentage points (a 33.4% relative increase); trials run by two government nudge units averaged +1.4 points (8.0%) across 126 RCTs; selective publication explains about 70% of the gap (L21).
- Large replication projects show that many published psychology findings do not hold up when repeated (L26). A single published study, or a single A/B win, is weak ground for a general rule.
